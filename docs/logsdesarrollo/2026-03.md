## 2026-03-13 — Entidad Profesional y refactorización del módulo Usuarios

**Motivación:** El modelo conceptual del documento `modulo-usuarios-permisos.md` distingue tres entidades con responsabilidades distintas: Usuario (identidad de autenticación), Profesional (perfil organizativo) y el marco de autorización (roles + UO). El código solo tenía la primera. Esta sesión implementa `Profesional` completo y alinea `usuario_rol` con el esquema definitivo del documento.

### Base de datos — migraciones nuevas

| Fichero | Tabla | Descripción |
|---------|-------|-------------|
| `database/migrations/2026_03_13_100001_create_versiones_table.php` | `versiones` | Snapshots históricos polimórficos. Usada por el trait `Versionable`. |
| `Modules/Usuarios/.../2026_03_13_100002_create_cargos_table.php` | `cargos` | Catálogo configurable de cargos profesionales. |
| `Modules/Usuarios/.../2026_03_13_100003_create_titulaciones_table.php` | `titulaciones` | Catálogo configurable de titulaciones académicas. |
| `Modules/Usuarios/.../2026_03_13_100004_create_tipos_relacion_profesional_table.php` | `tipos_relacion_profesional` | Catálogo: funcionario, interino, externo, voluntario... El campo `es_externo` activa el campo `organizacion` en Profesional. |
| `Modules/Usuarios/.../2026_03_13_100005_create_profesionales_table.php` | `profesionales` | Entidad principal. Datos laborales de una persona con independencia de si tiene cuenta de acceso. SoftDeletes. |
| `database/migrations/2026_03_13_100006_add_profesional_id_to_users_table.php` | `users` | Añade `profesional_id` (nullable FK). Nullable porque los perfiles técnicos puro (adm_sistema) no tienen función asistencial. |
| `Modules/Usuarios/.../2026_03_13_100007_recreate_usuario_rol_table.php` | `usuario_rol` | **Destructiva.** Recrea la tabla con el esquema definitivo: `usuario_id`, `rol_id` (FK a Spatie), `asignado_por`, `estado` (pendiente_aprobacion / activo / inactivo). |
| `Modules/Usuarios/.../2026_03_13_100008_create_configuracion_roles_table.php` | `configuracion_roles` | Extiende los roles de Spatie con `nivel_supervision` (aprobacion_previa / alerta_supervisada). Configurable desde backoffice. |
